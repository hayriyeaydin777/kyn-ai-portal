# Approval and Review Commands

## Implement one TODO

Implement TODO `<ID>` only. Reconfirm scope in one sentence, inspect existing files, make the smallest compliant change, add required tests, run relevant validation, report changed files and results, and stop. Do not begin another TODO.

## Split a TODO

Split TODO `<ID>` into small independently approvable sub-TODOs. Do not modify files. Stop after planning.

## Review without fixes

Review TODO `<ID>` against acceptance criteria, architecture, ADRs, security, and tests. Report findings by severity. Do not modify files. Stop.

## Fix selected findings

Fix only findings `<IDs>`. Do not perform unrelated refactoring. Run relevant tests, report results, and stop.

## Milestone review

Evaluate the current milestone against `06-MVP-Roadmap.md` and `09-Success-Metrics.md`. Do not modify files. Report evidence, gaps, and the next single action.
