# 16. Hiring-Team Evidence Matrix
- Application consulting: current-state discovery, options, tradeoffs, roadmap, executive brief.
- AI-assisted development: code review, tests, documentation, prompt versions.
- Modernization: deterministic assessment plus AI-supported target-state options.
- Architecture: ADRs, governance, diagrams, standards, review workflow.
- Agentic AI: shared runtime, tools, schemas, lifecycle, approval, evaluation.
- Software engineering: SvelteKit, FastAPI, .NET, contracts, persistence, migrations, tests.
- Security: authorization, redaction, injection defense, secrets, approval, audit.
- Operations: CI/CD evidence, telemetry, health/readiness, failures, SLO-style metrics.
