# 07. API Specifications
Use `/v1`, OpenAPI, validation, problem details, correlation IDs, authorization, idempotency, optimistic concurrency, and audit.

Primary resources: `/applications`, `/dependencies`, `/evidence`, `/assessments`, `/findings`, `/briefs`, `/modernization-cases`, `/code-reviews`, `/test-generations`, `/documentation-drafts`, `/architecture-decisions`, `/architecture-reviews`, `/agents`, `/agent-versions`, `/prompt-versions`, `/evaluation-datasets`, `/evaluation-runs`, `/approvals`, `/audit-events`, `/health/live`, `/health/ready`.

Generated artifacts remain drafts until approved. Tool execution and provider metadata are retrievable without exposing hidden reasoning or secrets.
