# 06. MVP Roadmap

00. **Architecture Reconciliation** - Reconcile v2 modules, ADRs, safety, scope, and terminology.
01. **Repository Foundation** - Scaffold SvelteKit, FastAPI, .NET, MySQL, Redis, CI, health, logs.
02. **Recovery Domain** - Implement profiles, dependencies, evidence, audit, persistence, and critical UI path.
03. **Deterministic Assessment** - Implement policy contract, rules, findings, evidence traceability, and contract tests.
04. **AI Briefing** - Implement provider abstraction, tools, grounded brief, citations, approval, and evaluations.
05. **Modernization Advisor** - Implement current-state schema, deterministic risk model, target options, roadmap draft, review and exports.
06. **AI Engineering Workspace** - Implement code review, test generation, and documentation drafts with read-only inputs and approval gates.
07. **Architecture Governance** - Implement ADR Assistant, architecture review, diagram metadata, standards, review workflow, and immutable decisions.
08. **Agent Platform** - Implement catalog, versions, tool allowlists, schemas, security tiers, lifecycle, and approval requirements.
09. **AI Evaluation** - Implement curated datasets, prompt versions, citation/schema/tool/safety metrics, failed evaluations, and dashboards.
10. **Hardening and Observability** - Implement identity, authorization, rate limits, fault handling, security scans, accessibility, traces, and SLO evidence.
11. **Showcase** - Create synthetic seed data, scripted demo, printable PDF, portfolio evidence matrix, and public-repository review.
