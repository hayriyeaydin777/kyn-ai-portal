# 14. Architecture Governance
## ADR workflow
Draft context and drivers; generate alternatives; document tradeoffs; run review checklist; link standards; submit to human reviewers; accept/reject; create immutable accepted version.
## Architecture review
Evaluate business alignment, security, privacy, reliability, performance, testability, operability, integration, data, and cost assumptions.
## Diagram governance
Store diagram source/metadata, version, scope, and linked ADRs. Diagrams never become the source of truth without reviewed contracts and decisions.
## Roles
Author, reviewer, approver, and administrator permissions are explicit. AI can draft but cannot approve.
