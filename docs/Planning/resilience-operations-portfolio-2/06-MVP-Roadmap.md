# 06. MVP Roadmap

- Milestone 0: reconcile architecture and safety documentation.
- Milestone 1: scaffold repository, SvelteKit, FastAPI, .NET, MySQL, Redis, CI, health/readiness, and logging baseline.
- Milestone 2: implement ApplicationProfile, dependencies, persistence, migrations, audit, and SvelteKit critical path.
- Milestone 3: implement versioned deterministic readiness assessment and contract tests.
- Milestone 4: implement provider abstraction, tools, grounding, structured briefs, citation validation, timeline, and approval.
- Milestone 5: harden identity, authorization, CSRF/CORS, rate limits, idempotency, worker failures, scanning, accessibility, and fault tests.
- Milestone 6: create synthetic seed data, demo script, architecture presentation, threat model, test evidence, and role-capability traceability.

Each milestone ends only when its documented exit criteria and tests pass.
