# 09. Success Metrics

Portfolio targets, not production claims:

- 100% of deterministic findings include rule IDs and evidence references.
- 100% of material generated claims include valid evidence IDs.
- Zero accepted unknown citations.
- Zero side effects without approval.
- Critical demo workflow passes end to end.
- All mutation routes validate input and authorization.
- Critical creates are idempotent.
- Every 4xx/5xx response carries a correlation ID.
- Migrations upgrade from an empty schema in CI.
- Contract checks detect unapproved breaking changes.
- Critical browser workflow has Playwright coverage.
- Critical pages have no serious automated accessibility violations.
- Correlation propagates across web, APIs, worker, and provider boundary.
- No committed secrets or unresolved critical dependency vulnerabilities.
