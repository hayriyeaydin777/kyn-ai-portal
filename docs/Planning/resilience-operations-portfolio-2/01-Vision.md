# 01. Vision

Enable application teams and consultants to assess recovery readiness, coordinate recovery-plan changes, and generate evidence-grounded operational guidance through a secure, observable platform.

The portfolio demonstrates SvelteKit, FastAPI, a focused ASP.NET Core policy service, relational persistence, contract-first APIs, testing, observability, and responsible Claude-compatible orchestration.

Core users: application owner, resilience consultant, operations engineer, and platform administrator.

Core outcomes: maintain recovery profiles, define objectives and dependencies, run deterministic checks, generate cited briefs, require approval for consequential actions, and trace changes through audit events.

Non-goals: real recovery execution, production data, autonomous remediation, or a general-purpose chatbot.
